# Notebooks

Analysis notebooks organized by weekly task.

| Folder | Notebook | Description |
|--------|----------|-------------|
| `task-1/` | `eda.ipynb` | Descriptive stats, publisher analysis, topic keywords, publication trends |
| `task-2/` | `technical_analysis.ipynb` | TA-Lib indicators (SMA, RSI, MACD) and visualizations |
| `task-2/` | `financial_demo.ipynb` | yfinance exploration and event-driven analysis demo |
| `task-3/` | `sentiment_return_correlation.ipynb` | End-to-end sentiment vs. return correlation using `src/` modules |
| `task-3/` | `correlation_exploration.ipynb` | Standalone correlation methods (Pearson, Spearman, Kendall) |

Run notebooks from the repository root or ensure `src/` is on `PYTHONPATH`.
